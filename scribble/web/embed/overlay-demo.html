Testing Programs for Code Coverage with Scribble

Recall the following program from lecture (some comments have been added):

#include <stdio.h>
int main () {
    int A, B, C, D;
    printf ("Please enter three numbers: ");
    if (3 != scanf ("%d%d%d", &A, &B, &C)) {
        printf ("Invalid input.\n");   /* PART ONE */
        return 3;
    }
    if (A < B) { D = A; A = B; B = D; }   /* PART TWO */
    if (A < C) { D = A; A = C; C = D; }   /* PART THREE */
    if (B < C) { D = B; B = C; C = D; }   /* PART FOUR */
    printf ("The numbers are %d, %d, and %d.\n", A, B, C);
    return 0;
}

The program is tested with the following three user inputs: "hello", then 1 2 3, then 3 2 1. For each part, state whether the tests achieve full branch coverage and justify your answer. Annotate the code directly using the scratchpad.
